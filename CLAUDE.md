# CLAUDE.md — working rules for this repo

SAFE-GIFT is a peer-to-peer custom-gifting marketplace backend. Customers post gift
requests; verified couriers invoice and deliver; money moves through an escrow ledger.

All 14 build phases are complete. The codebase was re-audited on 2026-07-31; remediated
findings, remaining production blockers, and accepted trade-offs are tracked in
`docs/audit/README.md`. Read it before changing security, money, storage, or integration
behavior, and update the audit whenever a finding changes state or a new risk appears.

## THE HARD RULES

- **`uv` only, never `pip`.** No `requirements.txt`, poetry, pipenv, virtualenv, conda —
  anywhere (local, Docker, CI, docs).
- **Money is `Decimal`, never `float`.** Parse from strings, serialize to strings.
  Quantize only through `app/core/money.py`. Pricing lives only in `app/core/pricing.py`.
- **No raw SQL strings.** SQLAlchemy bound params; unavoidable PostGIS uses `text()` with
  `:named` params. Never f-string SQL.
- **Ownership is enforced in the query,** never fetch-then-compare. The actor id comes
  from the verified JWT, never the request body.
- **The ledger is append-only.** `transactions` allows no UPDATE/DELETE except the
  trigger-enforced `PENDING -> SETTLED|REVERSED`. Corrections are compensating entries.
- **Secrets from env only.** No secrets manager. Wrap every secret in `SecretStr`; never
  log or bake one into the image.
- **No healthcare data.** Out of scope; do not collect, infer, store, or design for it.
- **Base path `/api` with no version prefix.** `/api/v1/` is forbidden.

## Layering & the dependency rule

`routers/ | admin/  ->  services/  ->  repositories/  ->  models/`, never reversed.
`core/` is shared primitives. A module imports another module's **service interface**
only — never its repository or tables. Routers/admin do zero business logic and zero
direct DB queries. Services never import FastAPI or touch Request/Response.

Where a change belongs: HTTP contract -> `routers/` + `schemas/`; business rule ->
`services/`; a new query -> `repositories/`; a column/constraint -> `models/` + an
Alembic migration; a fee/tax rule -> `core/pricing.py`.

## Conventions

- Naming per SPEC SECTION 7: tables plural snake_case; PK always `id` (UUID); money
  columns suffix `_amount`/`_balance`; encrypted columns suffix `_encrypted`.
- Conventional Commits (`feat|fix|refactor|perf|test|docs|chore|ci|build`).
- Google-style docstrings on every module, public class/function, schema, model, and
  custom exception (ruff `D` rules enforce this).

## Before you finish ANY change

- Run `uvx ruff check`, `uvx ruff format --check`, `uv run mypy app`, and `uv run pytest`.
- Update `docs/` if a contract moved (a route change with no doc change fails review).
- Add a test for every behaviour change.
- Never commit a secret, a real `.env`, or an unread autogenerated migration.

## Where the money invariants live (do not touch casually)

- `core/money.py` — the only place money is quantized.
- `core/pricing.py` — the only place a price is built; the 655.50 golden example is the
  regression anchor.
- The ledger double-entry rule (every `correlation_id` group sums to 0.00) and the
  wallet balance invariant (`balance == SUM(settled amounts)`) are enforced by the money
  service and the nightly reconciliation job. Changing them requires a matching test and
  an ADR.

## Known traps

- `ST_MakePoint` takes **longitude first** — reversing it puts Jeddah in Antarctica.
- `ST_Distance` on `geometry` returns **degrees**; cast to `geography` for metres.
- A plain Redis `DEL` can release someone else's lock — release with a Lua
  compare-and-delete on your random token.
- A sync SDK call inside an async handler stalls the whole event loop — wrap it in
  `run_in_threadpool`.
- Verify the StreamPay webhook signature over the **raw** body, never the re-serialized
  dict.
